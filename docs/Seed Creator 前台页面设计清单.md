# Seed Creator 前台页面设计清单

**用途：** 发给设计师，说明本次种子用户激励计划需要重出视觉的页面。  
**现状：** 前台已按功能跑通，当前是功能草稿，视觉可以整页重做。  
**说明：** 同一 URL 会随用户状态切换，请按状态分别出稿，不要只出一张图。

---

## 一、全新页面（优先）

### 1. 活动页

路径：`/activity/seed-creator`  
入口：顶栏「种子计划 / Seed Creator」、页脚同名链接

请分别出这些状态：

| 状态 | 页面上要有什么 |
|---|---|
| 未登录 / 未报名 | 活动介绍、核心权益（前 30 名 $20 Bonus）、参与步骤、CTA「立即参加」 |
| 报名表单 | Twitter/X 用户名、主页链接；Discord 用户名、User ID；至少填一项即可提交 |
| 审核中 | 已提交、等待人工审核；允许更新资料再提交 |
| 审核未通过 | 失败说明 + 可再次提交表单 |
| 已成为 Seed Creator | 祝贺文案、排名、$20 Bonus、邀请链接（可复制）、已邀请人数、邀请奖励状态（等待首位成功邀请 / 已领取 / 已失效） |
| 邀请列表 | 用户（打码）、是否注册、是否首充、状态（观察中 / Winner / 已失效 / 无奖励）、剩余有效期 |
| 活动已结束 | 只读，不能再报名 |
| 暂无活动 | 空状态 |

### 2. 被邀请页

路径：`/invite/{邀请码}`  
用户从 Seed Creator 分享的链接进来

请分别出这些状态：

| 状态 | 页面上要有什么 |
|---|---|
| 未登录 | 说明「你正在通过好友邀请参加」+ 步骤（注册 → 3 天内单笔充值 ≥ $10）+ 登录 CTA |
| 绑定中 | 加载中 |
| 已绑定、等待首充 | 倒计时 / 3 天规则 + 去充值 |
| Winner | 祝贺「你是首位成功被邀请人」+ 自己 +$10，并说明邀请人也 +$10 |
| 绑定失败 | 邀请码无效、自己邀自己、活动已关闭、已经充过值不能再绑等错误态 |

补充：如果该邀请的 $10 名额已被别人抢走，需要有 **「已达标但无奖励」** 状态（你完成了条件，但奖励已发给其他人）。

## 二、已有页面要改（次优先）

### 3. 账单页

路径：`/billing`

新增 / 调整：

- 余额拆成：**可用总额 / Cash / Bonus**
- 新增 **Bonus 明细列表**：每笔来源（Seed Creator 奖励 / 邀请奖励 / 被邀请奖励 / 手动补发）、剩余金额、到期时间、状态（可用 / 已用完 / 已过期 / 已冻结）
- 文案说明：Bonus 不可提现、不可退款，优先于 Cash 消耗，到期失效

### 4. 全局导航

- 顶栏：新增「种子计划」入口（桌面 + 移动端菜单）
- 页脚：新增同名链接
- 顶栏余额：现在是 Cash + Bonus 合计，如需拆开展示请一并设计

## 三、这次不用出（不在用户前台）

管理后台（审核队列、邀请表、Bonus 补发 / 冻结、活动 Dashboard）走另一套 admin，不在这次前台改版范围。

## 四、出稿时用的活动规则

- 前 30 名完成 Twitter/X + Discord 审核 → Seed Creator，得 **$20 Bonus**
- Seed Creator 可邀请多人，但 **只有 1 个 Winner**
- Winner 条件：注册后 **3 天内**，**首次单笔充值 ≥ $10**
- Winner 与邀请人各得 **$10 Bonus**
- Bonus 领取后 **14 天**内有效（且不晚于活动结束）

当前测试环境这些页面已经能点通，建议对照真实页面出稿，而不是只看文档线框。
