# Seed Creator 前台测试手册

按下面的路径从上往下点即可。每条路径写明「用谁、打开哪、点什么、看到什么」。勾完主路径再跑分支。

**依据：** 页面设计清单、PRD V1.5  
**范围：** 用户前台（不含管理后台）  
**页面：** `/activity/seed-creator` · `/invite/{邀请码}` · `/invite` · `/billing` · 头像下拉

---

## 怎么测

1. 先做「测试准备」，账号和环境齐了再开始。
2. **路径 A 必测**，一条故事从头走到尾。
3. 路径 B～H 按时间/账号条件穿插；发版前至少把 A + B + D + F 跑完。
4. 每步旁边勾：`[x]` 通过 / 失败就记到文末缺陷表。

**规则对照（看结果时用）：**

- 前 30 名审核通过 → Seed Creator + **$20 Bonus**
- 可邀请多人，每位 Seed Creator 只有 **1 个 Winner**
- Winner：绑定后 **3 天内**，**首次单笔充值 ≥ $10**（拆分不算）
- Winner 与邀请人各得 **$10 Bonus**
- Bonus：不可提现、不可退款；领取后 **14 天**有效，且不晚于活动结束；消费时 **优先于 Cash**

**入口对照：**

| 入口 | 谁能看见 | 点进去 |
|---|---|---|
| 顶栏 / 页脚 / 移动菜单 | 谁都不该看见公开入口 | — |
| 头像「种子计划」 | 报过名的 Seed Creator（审核中/通过/拒绝）；被邀请人即使 `me` 有值也不显示 | `/activity/seed-creator` |
| 头像「好友邀请」 | profile 里 `invited_code` 非空 | `/invite` |
| 运营私发链接 | 任何人可直达 | `/activity/seed-creator` |

被邀请人状态只看 `GET /activity/seed-creator` 的 `me.invite`。**不要**出现 `GET /activity/referral/invitation`（接口不存在）。

## 测试准备

### 账号（建议提前开好，路径里用字母指代）

| 账号 | 是谁 | 怎么准备 |
|---|---|---|
| A | 未登录访客 | 隐身窗口，无账号 |
| B | 新用户，准备报名 Seed Creator | 全新邮箱 |
| C | 就是 B，审核通过后变成 Seed Creator | 跑路径 A 时由后台通过 |
| D | 已有 Winner 的 Seed Creator | 路径 A 走完后的 C |
| E | 被邀请人（将成 Winner） | 全新邮箱，隐身窗口 |
| F | 第二个被邀请人（将成 NO_REWARD） | 全新邮箱，另一个隐身窗口 |
| G | 已充过值的老用户 | 历史上有成功充值 |
| H | 活动已结束 / 暂无活动 | 需运营切环境 |

隐身窗口建议：窗口 1 = 账号 B/C；窗口 2 = 账号 E；窗口 3 = 账号 F。不要串登录态。

### 环境勾选

- [ ] 测试环境活动已开启，名额未满
- [ ] 后台能审核通过 / 拒绝
- [ ] 能完成真实或模拟的单笔 ≥ $10 充值
- [ ] 可选：能把活动切到「已结束」「无活动」
- [ ] `GET /user/profile` 有 `invite_code` / `invited_code`（没有则为 null）
- [ ] Seed Creator 的 `me.invite` 为 null；被邀请人的 `me.invite` 为对象

## 路径 A · 主流程（必测）

一条线：访客看到活动 → 报名 → 审核通过拿 $20 → 邀请好友 → 好友单笔 ≥ $10 → 双方各拿 $10。

### A1 未登录看活动页

**用：** 账号 A（隐身，未登录）  
**打开：** 运营发的 `/activity/seed-creator`

- [ ] 能打开落地页，不依赖顶栏导航
- [ ] 有活动介绍、核心权益（前 30 名 $20 Bonus）、参与步骤、CTA「立即参加」
- [ ] 规则区写清：前 30 名、$20、1 个 Winner、3 天内单笔 ≥ $10、双方各 $10、Bonus 14 天且不晚于活动结束
- [ ] 顶栏 / 页脚 **没有**「种子计划」「好友邀请」
- [ ] 点「立即参加」→ 去登录/注册

### A2 登录后报名

**用：** 账号 B（刚在上一步注册/登录）  
登录成功应回到活动页。

- [ ] 已登录未报名：能看到规则和报名表单
- [ ] 表单有：Twitter/X 用户名、主页链接；Discord 用户名、User ID；确认勾选
- [ ] 空白直接提交 → 交不出去
- [ ] 不勾选确认 → 交不出去
- [ ] **只填完整 Twitter/X**（用户名 + URL）→ 能提交成功
- [ ] （可选再测一次新号）只填完整 Discord，或两项都填，也能提交
- [ ] 提交成功：提示「已提交，等待审核」；页面进入审核中
- [ ] 打开头像下拉：**出现「种子计划」**，**没有「好友邀请」**
- [ ] （可选）DevTools：`seed-creator` 的 `me` 非空、`invite` 为 null

### A3 审核中

**用：** 还是账号 B，刷新活动页

- [ ] 展示「审核中」，说明在等人工审核
- [ ] 能看到已提交资料摘要（有提交时间则核对）
- [ ] 刷新后仍是审核中，资料还在
- [ ] 点「更新资料」改完再提交 → 仍保持审核中
- [ ] 头像下拉仍有「种子计划」，点进去还是本页

### A4 审核通过，成为 Seed Creator

**配合：** 后台把 B 审核通过。刷新活动页。账号 B 此后称 **账号 C**。

- [ ] 祝贺文案；有排名（如 #n）；Creator Bonus $20 已领取
- [ ] 有专属邀请链接，形如 `/invite/{code}`
- [ ] 点复制 → 提示已复制；粘贴内容和页面一致
- [ ] 邀请奖励状态：**等待首位成功邀请**
- [ ] 邀请列表空状态（还没有好友通过链接注册）
- [ ] 打开 `/billing`：有一笔 **Seed Creator 奖励 $20**，状态可用
- [ ] 账单余额拆分：可用总额 / Cash / Bonus；文案写明不可提现、不可退款、优先扣 Bonus
- [ ] 顶栏余额与账单 Cash + Bonus 合计一致
- [ ] 直接打开旧路径 `/activity/seed-creator/invitations` → 没有独立列表页（404 或站点未匹配路由）

把邀请链接记下来，给下一步用。

### A5 被邀请人打开链接、绑定

**用：** 账号 E（新隐身窗口，未登录）  
**打开：** 上一步复制的 `/invite/{code}`

- [ ] 未登录页：说明「通过好友邀请参加」；步骤含注册 → 3 天内单笔 ≥ $10；有登录 CTA
- [ ] 文案提示登录后会绑定该邀请码
- [ ] 点登录，完成注册/登录 → **自动绑定**，不用手输邀请码
- [ ] 绑定过程有短暂「绑定中」
- [ ] 绑定成功 → 「已绑定、等待首充」；有倒计时和「去充值」
- [ ] 规则写明：拆分不算、必须单笔 ≥ $10、仅 1 个 Winner
- [ ] 倒计时在走，格式可读（天 + 时分秒）
- [ ] 打开头像下拉：**出现「好友邀请」**，**没有「种子计划」**
- [ ] DevTools Network：**没有** `/activity/referral/invitation`；能看到 `/activity/seed-creator`，绑定过程有 `/activity/referral/bind`
- [ ] 点头像「好友邀请」→ 进 `/invite`（无邀请码），仍是等待首充，倒计时用 `me.invite.deposit_deadline`
- [ ] 再打开原来的 `/invite/{code}` → 仍按已绑定状态展示，不重复绑定报错

### A6 被邀请人单笔充值 ≥ $10，成为 Winner

**用：** 账号 E  
**操作：** 点「去充值」，完成 **一笔** ≥ $10 的成功充值（不要拆成两笔）。

- [ ] 刷新邀请页：祝贺 Winner；说明自己 +$10，邀请人也 +$10
- [ ] 打开 `/billing`：有 **被邀请奖励 $10**
- [ ] 头像「好友邀请」仍在，点进去还是 Winner 页，不会重新绑定

**切回窗口 1，账号 C：**

- [ ] `/billing`：多一笔 **邀请奖励 $10**
- [ ] 活动页：邀请奖励状态变为 **已领取**
- [ ] 邀请列表：该用户状态 **Winner**；有效期可显示已完成；用户信息已打码
- [ ] 已邀请人数 = 列表条数

主路径到这里结束。接下来用同一条邀请链接测「第二人没奖励」。

## 路径 B · 第二人达标但无奖励

**前置：** 路径 A 已产生 Winner。同一条邀请链接继续用。  
**用：** 账号 F（第三个隐身窗口）

1. 打开同一 `/invite/{code}` → 注册登录 → 绑定成功 → 等待首充。
2. 同样完成 **单笔 ≥ $10** 充值。
3. 刷新邀请页。

- [ ] 文案是「已完成条件，但奖励名额已满 / 无奖励」，不是 Winner
- [ ] `/billing`：充值进了 Cash，**没有**再发 $10 邀请 Bonus
- [ ] 切回账号 C 的活动页：该条列表状态 **无奖励**；邀请奖励仍是已领取（不会发第二份）
- [ ] 账号 F 头像有「好友邀请」，点 `/invite` 仍是无奖励态

---

## 路径 C · 审核拒绝后再通过

另开一个全新账号（不要用已经通过的 C）。

1. 打开活动页 → 登录 → 提交报名。
2. **后台拒绝**。刷新活动页。
3. 改资料，点重新提交。
4. **后台再通过**。

- [ ] 拒绝后有失败说明（有原因展示原因，否则兜底文案）
- [ ] 「重新提交」可用，不是永久封禁
- [ ] 再提交后回到审核中
- [ ] 再通过后能成为 Seed Creator（名额未满时），$20 到账

---

## 路径 D · 邀请绑定失败

每条用独立隐身窗口。失败页都要有说明 + 错误码（如有）+ 返回首页等出口，不白屏。

| 怎么操作 | 预期 |
|---|---|
| 打开 `/invite/不存在的码`，登录后绑定 | 邀请码无效 |
| 账号 C 打开 **自己的** 邀请链接并尝试绑定 | 自己邀自己不允许 |
| 账号 G（历史上已成功充值）打开有效邀请链接并绑定 | 已经充过值不能再绑 |
| 账号 E（已绑定 C）再打开 **另一个** Seed Creator 的邀请链接 | 不可改绑，保持第一次关系 |
| 活动已关闭后，用邀请码绑定（需切环境） | 活动已关闭类提示 |

- [ ] 无效码
- [ ] 自己邀自己
- [ ] 已充值用户不能绑
- [ ] 不能改绑
- [ ] 活动关闭（有环境再测）
- [ ] 任意错误态不白屏

---

## 路径 E · 充值规则（不要发错奖）

另准备「已通过、还没有 Winner」的 Seed Creator，复制其邀请链接。每条规则用 **新的被邀请人**。测完若产生了 Winner，这条邀请链接后续只能用来测 NO_REWARD，不要混用。

| 操作 | 预期 |
|---|---|
| 先充 $5，再充 $5 | **不**达标，不产生 Winner |
| 首笔成功充值 $9.99 | 不达标 |
| 首笔成功充值正好 $10（且是首位、在 3 天内） | 达标，成为 Winner |
| 绑定后等到第 4 天才充 ≥ $10 | 已失效，不发邀请奖；列表「已失效」 |
| 多人注册但谁都不充 | 邀请人仍是「等待首位成功邀请」；列表可多条「观察中」 |
| 其中一人观察中过期 | 仅该条「已失效」；邀请人仍可继续邀请，机会未消耗 |

- [ ] 拆分 $5+$5 不算
- [ ] $9.99 不算
- [ ] 正好 $10 算
- [ ] 第 4 天过期
- [ ] 无人充值时机会还在
- [ ] 过期只影响那一条

过期后：邀请人继续把同一链接发给新人，新人仍能绑定（邀请奖励若还没 Winner，状态仍是等待中）。

## 路径 F · 入口、回访、语言（抽 10 分钟）

任意已登录页面操作。中英文可穿插。

**未登录**

- [ ] 没有头像下拉，故没有两条活动入口
- [ ] 运营链接仍能打开活动页

**从未报名、也不是被邀请人**

- [ ] 头像下拉：没有「种子计划」，没有「好友邀请」

**账号 C（Seed Creator）**

- [ ] 头像有「种子计划」，点进 `/activity/seed-creator`
- [ ] 没有「好友邀请」（除非这个号同时又被别人邀请过）

**账号 E（被邀请人）**

- [ ] 头像有「好友邀请」，点进 `/invite`，按当前状态恢复（等待 / Winner / 无奖励）
- [ ] **没有「种子计划」**（即使 `me` 对象存在）
- [ ] 绑定成功后不用手动刷新，下拉里就会出现「好友邀请」

**公共**

- [ ] 桌面顶栏、移动端菜单、页脚都没有公开活动入口
- [ ] 切中文：「种子计划」「好友邀请」；切英文：Seed Creator / Friend invite，无缺 key
- [ ] 活动页、邀请页各主要状态切语言，无英文 key 裸露
- [ ] 有 Cash / Bonus 时，顶栏总额正确（合计 = Cash + Bonus）

## 路径 G · 账单 Bonus 消耗

**用：** 账上同时有 Cash 和 Bonus 的账号（路径 A 的 C 或 E 即可）。打开 `/billing`。

- [ ] 余额：**可用总额 / Cash / Bonus** 数值正确
- [ ] Bonus 明细每笔有：来源、剩余金额、到期时间、状态
- [ ] 来源能对上：Seed Creator 奖励 $20 / 邀请奖励 $10 / 被邀请奖励 $10（有手动补发则也能看到）
- [ ] 无 Bonus 的号打开明细 → 「暂无 Bonus」
- [ ] 发起一笔消费 → **先扣 Bonus，再扣 Cash**
- [ ] 多笔 Bonus 到期日不同时，先扣 **更早到期** 的那笔
- [ ] 用掉一部分：剩余金额减少，状态仍为可用
- [ ] 用尽：状态「已用完」
- [ ] 过期或活动结束后清零：状态「已过期」，余额里 Bonus 减少/为 0
- [ ] 有冻结（环境支持才测）：状态「已冻结」
- [ ] 顶栏余额与账单一致

---

## 路径 H · 活动结束 / 无活动 / 名额满

需运营切环境，有条件再测。

**活动 ended**

- [ ] 未报名用户打开活动页：只读结束态，不能再报名
- [ ] 已是 Seed Creator：能看历史数据和邀请列表，不能新报名，邀请相关只读
- [ ] 用邀请码绑定：失败，活动已关闭
- [ ] 未用完的 Bonus：清零或显示已过期（与结束任务一致）

**暂无活动**

- [ ] 打开活动页：「暂无活动」空状态，有返回首页等出口

**名额 30/30**

- [ ] 新用户不能再获得 Seed Creator / $20（提示与后端策略一致）
- [ ] 已有 30 名后再审通过第 31 人：不能成为 Seed Creator（以后端为准）

## 路径 I · 体验与异常（穿插即可）

- [ ] 桌面 / 手机宽度：活动页、邀请页、账单布局可用，主按钮能点，无严重遮挡
- [ ] 复制邀请链接：成功有提示；失败有兜底
- [ ] 倒计时跨天刷新：连续正确，不出现负数乱跳
- [ ] 登出再进活动页：回到未登录落地页，不串上一个账号的数据
- [ ] 浏览器后退、或直接贴 URL 进入各状态：和当前账号一致，不要先闪错误再变对
- [ ] 断网 / 活动页 API 失败：有失败提示和「重试」，不白屏
- [ ] 邀请列表 API 失败：活动页其余内容仍可用，列表空或不阻断主流程
- [ ] 填明显非法 URL / 空格脏数据提交报名：有校验或后端错误提示，不白屏
- [ ] 两个被邀请人几乎同时完成 ≥ $10：只有一人 Winner，另一人无奖励（可与后端联调）

## 发版前快速勾一遍

把上面路径跑过即可，这里只作漏项检查：

**活动页** — 未登录/未报名 · 表单 · 审核中 · 拒绝再提交 · 已通过（排名/$20/链接/人数/奖励状态）· 邀请列表 · 已结束 · 暂无活动

**被邀请页** — 未登录 · 绑定中 · 等待首充 · Winner · 无奖励 · 绑定失败 · `/invite` 无码回访 · Network 无 `referral/invitation`

**入口与账单** — 无公开导航 · Seed Creator 见「种子计划」· 被邀请人见「好友邀请」且不见「种子计划」· 运营链接可直达 · Cash/Bonus 拆分与优先扣费

**主规则** — 多人邀请仅 1 Winner · 单笔 ≥ $10 · 3 天按被邀请人独立算 · Bonus 与 Cash 分离
