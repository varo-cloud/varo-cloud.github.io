# Seed Creator 前台测试用例

**依据文档：**
- `docs/Seed Creator 前台页面设计清单.md`
- `docs/Varo Seed Creator Referral Program｜种子用户激励计划 PRD V1.5.md`

**测试范围：** 用户前台（不含管理后台）  
**覆盖页面：**
| 路径 | 说明 |
|---|---|
| `/activity/seed-creator` | 活动页（随用户状态切换；运营私发链接，无全局导航） |
| `/invite/{邀请码}` | 被邀请页；已绑定用户也可打开 `/invite` 回访 |
| `/billing` | 账单 / Bonus 明细 |
| 头像下拉菜单 | 「种子计划」回访 Seed Creator；「好友邀请」回访被邀请人 |

**核心规则速查（验收时对照）：**
- 前 30 名审核通过 → Seed Creator + **$20 Bonus**
- 可邀请多人，但每位 Seed Creator 只有 **1 个 Winner**
- Winner：注册并绑定后 **3 天内**，**首次单笔充值 ≥ $10**
- Winner 与邀请人各得 **$10 Bonus**
- Bonus：**不可提现、不可退款**；领取后 **14 天**有效，且不晚于活动结束；消费时 **优先于 Cash**

**头像入口（与接口字段对齐）：**
- 「种子计划」：`GET /activity/seed-creator` 返回 `me != null` **且** `me.invite == null` 才显示（报名过的 Seed Creator / 审核中 / 拒绝等；**被邀请人即使 `me` 有值也不显示**）
- 「好友邀请」：`GET /user/profile` 的 `invited_code` 非空才显示（被邀请人回访 `/invite`）
- 被邀请人状态从 `me.invite` 读取（`status` / `deposit_deadline` / `is_winner` 等）；**不再请求** `GET /activity/referral/invitation`（该接口不存在）

## 5. 端到端主流程（必测）

建议按顺序跑通一遍。

### 5.1 Seed Creator 主路径

| ID | 步骤 | 预期 | 结果 |

| E2E-04 | 被邀请人 **单笔**充值 ≥ $10（成功） | 成为 Winner；双方各 +$10 Bonus | |
| E2E-05 | 邀请人刷新活动页 | 奖励状态已领取；列表 Winner | |

### 5.2 否定路径（规则边界）

| ID | 步骤 | 预期 | 结果 |
|---|---|---|---|
| E2E-N01 | 被邀请人先充 $5，再充 $5 | **不**达标；不产生 Winner | |

- [ ] 绑定中

- [ ] 3 天有效期按 Invitee 独立计算
